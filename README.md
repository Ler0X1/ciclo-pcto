# Ciclo PC-TO

App de ciclo de estudos para o concurso da Polícia Civil do Tocantins (Oficial Investigador).

- Mostra o bloco da vez (matéria e conteúdo), com cronômetro de 60 minutos.
- 14 blocos por volta, 11 matérias, conteúdos em ordem de estudo.
- Funciona offline e pode ser instalado no celular.
- O progresso fica salvo no próprio aparelho.

Endereço: https://ler0x1.github.io/ciclo-pcto/
